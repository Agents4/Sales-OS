# Outreach draft

A message earns the next conversation. Draft it in the buyer's language, ask for one small and easy commitment, and keep every internal insight out of it.

Read `references/operating-rules.md` (rule 4 especially) and `references/capabilities.md`. Use `references/conceptual-selling.md` for the commitment logic (Best Action Commitment and Minimum Acceptable Action).

## When to use

- First contact or re-engagement.
- A follow-up after a call (pair with `mh-call-debrief`).
- A note to an executive, a request for an introduction, a meeting request.

## Inputs

Recipient and role, the purpose, any history, what the buyer has said in their own words, the Blue Sheet (internal use only), and the user's voice rules in `workspace/context-library/writing-style.md` if it exists. If it does not, ask for one or two examples of messages the user is proud of, or use plain, direct, short prose.

## Procedure

1. **Define the objective.** The smallest commitment that moves things forward (a reply, a 20-minute call, an introduction, a document review). Make it easy to say yes.
2. **Find the hook.** A real reason to write now, from a verified source: their own stated goal, an event, a public announcement, a mutual contact. If none is verified, say so and write a plainer message. Never invent a trigger, a mutual connection or a metric.
3. **Use the Concept.** Reflect what they have said in their words, not a product pitch. One idea only.
4. **Draft** short, specific and in the user's voice: opening that earns attention, one relevant sentence of substance, one clear ask with a time frame. No filler, no flattery, no hype.
5. **Offer up to two variants** that differ in approach (for example more direct, more consultative), not in wording.
6. **Leak check (mandatory).** Remove or avoid: modes, Wins, support ratings, red flags, Coach references, competitor assessments, internal forecast, pricing strategy. Never name a person as the source of information if the source was the Coach. Do not reference internal analysis ("we understand you are in Trouble mode").
7. **Mark as draft.** Do not send, schedule or create the email. If Gmail drafts are available and the user asks, create a draft only.

## Output

Subject line (for email), body, and a one-line note on the intent of each variant. With file access, save to `workspace/outputs/drafts/YYYY-MM-DD-<recipient>.md` with `status: draft`.

## Quality gate

1. Every factual claim in the message is sourced or came from the user.
2. One ask, with an easy yes.
3. Leak check run and reported in one line.
4. Voice matches the user's rules; no invented personalization.
